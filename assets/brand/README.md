# RelixZoon logo files

Supplied by RelixZoon and used unchanged (only trimmed and resized):

- `relixzoon-wordmark.webp` / `.png` — word logo, transparent background (navigation and footer)
- `relixzoon-icon-512.png`, `relixzoon-icon-192.png` — drawn logo / app icon
- `apple-touch-icon.png`, `favicon-32.png`, `favicon-48.png`, `../../favicon.ico` — browser and phone icons

To swap the logo later, upload a new file with the same name.
